# Development roadmap

## Completed

- Phase 1: monorepo foundation and development commands
- Phase 2 foundation: MongoDB connection, core models, Firebase authentication
  and role authorization, employee profile read/update, and the skill catalog
  with employee skill management
- Phase 3 foundation: consent-gated Gemini transferable-skills analysis,
  validated and saved analysis results, and employee analysis history
- Phase 4 foundation: curated occupational role catalog and transparent,
  active-skill-overlap recommendations with duties and skill utilization
- Phase 5 foundation: employer company profiles, admin verification queue,
  verification decisions, and re-review after profile edits
- Phase 6 foundation: verified-employer employee search limited to public
  profiles with contact and employer details excluded
- Phase 7 foundation: consent-gated AI role-skill identification with local,
  public-profile candidate ranking by skill overlap

## Implementation order

1. Project setup and architecture
2. MongoDB connection and Mongoose models
3. Firebase authentication and role authorization
4. Employee registration and profile APIs
5. Skills and categorization
6. Gemini AI integration
7. Job roles and utilization
8. Employer profiles and verification
9. Employer dashboard and employee search
10. Workforce requirement matching
11. Separate admin employee/employer management pages
12. PDF reports, tests, security review, and deployment

## Definition of done for each phase

- Real persistence or external service integration
- Frontend and backend validation
- Authentication and authorization coverage
- Focused tests
- Error, loading, and empty states
- Updated API and environment documentation
