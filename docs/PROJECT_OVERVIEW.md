# Project overview

WorkforceIQ converts employee capabilities into practical workforce
opportunities. It is not a job-title-only recommender: every AI result is
expected to describe the employer use case, practical duties, department,
supporting skills, qualifications, and training required.

The platform has three authorization roles:

| Role | Responsibilities |
|---|---|
| Employee | Maintain profile and skills, explore matched roles, generate analysis |
| Employer | Maintain and verify company, search public profiles, match job skills |
| Admin | Manage users and master data, monitor AI and platform activity |
